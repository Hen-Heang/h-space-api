# deploy/ — retired VPS stack

These files ran h-space-api on a single VPS behind Caddy
(`docs/deploy-vps.md`). **The VPS is no longer used (2026-11-25)**:
h-space-api deploys to Railway from the repo-root `Dockerfile` — see
`docs/deploy-railway.md`.

Kept for reference and as a self-hosting example. Nothing builds or deploys
from this folder.
